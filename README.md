# 视频控制器 (Video Controller)

油猴视频控制脚本，全网站通用的 HTML5 播放器增强工具。

## 功能

### 视频控制
- **倍速**: 0.25x - 16x，固定倍速快捷键
- **音量**: 0x - 5x（>100% 通过 AudioContext 增益）
- **亮度**: 0x - 3x（CSS filter）
- **快进/快退**: 自定义秒数
- **逐帧前进/后退**
- **画面缩放**: 0.1x - 5x，步长可调，超出播放器居中显示
- **画面拖动**: 快捷键开启后鼠标拖拽移动画面

### 视觉功能
- 屏幕全屏 / 网页全屏
- 旋转 90°
- 水平翻转
- 截图（复制到剪贴板）
- 画中画
- 纯净模式（隐藏播放器控件和弹幕）
- 色彩模式：11 种预设 + 亮度/对比度/饱和度/色调手动调节

### 区间循环
- A-B 循环播放，支持任意次数

### 自动化
- **全局自动**: 进入任意网站自动应用倍速/音量/亮度设置
- **站点记忆**: 自动记录每个网站的播放状态，下次访问自动恢复
- **禁止站点**: 指定网站不使用站点记忆
- 优先级：站点记忆 > 全局自动

### 其他
- 快捷键支持 Ctrl / Alt 组合键
- 设置入口可隐藏，支持快捷键打开
- 所有设置持久化存储
- 4 页设置面板，记住上次关闭的标签页
- B站切集保留倍速/音量/亮度

## 适用网站

所有使用 HTML5 `<video>` 播放器的网站。

**已知不适配**: 腾讯视频 / QQ视频（WASM 渲染，非标准播放器）

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. [点击安装脚本](https://gitee.com/qiuzongman/video-controller/raw/master/video-controller.js)

## 快捷键（默认）

| 功能 | 快捷键 |
|------|--------|
| 暂停/播放 | Space |
| 倍速+ | W |
| 倍速- | S |
| 音量+ | ↑ |
| 音量- | ↓ |
| 亮度+ | + |
| 亮度- | - |
| 快进 | → |
| 快退 | ← |
| 固定倍速 1-4 | 1 / 2 / 3 / 4 |
